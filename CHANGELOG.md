# Changelog

All notable changes to ProjectFinder are documented here.

## 1.0.0 - 2026-07-25

### Added

- Custom email authentication with seeded Student and Staff roles.
- Responsive student directory with partial-name search and interest filtering.
- Read-only staff profiles with biographies, interests and project ideas.
- Owner-constrained staff dashboard and complete interest/project CRUD.
- Named deletion confirmations, validation, messages and empty states.
- Repeatable fictional dataset with exact demonstration credentials.
- Server-side role, ownership, CSRF, session and response-header controls.
- Database indexes supporting ordered profile/content retrieval.
- Cross-platform setup and verification scripts.
- GitHub Actions migration, test and 95% coverage checks.
- 59 automated tests with 97% assessed-code coverage.
- Architecture, maintenance, testing, demo, traceability and AI-use documents.

### Data notice

Every person, account, biography, interest and project idea is fictional and
exists only for academic demonstration.
