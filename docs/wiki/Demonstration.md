# Demonstration

The assessment demonstration should last 3-5 minutes.

## Student section

1. Sign in with the Student demonstration account.
2. Browse the complete directory.
3. Search for part of a staff name.
4. Filter by an area such as `Graph theory`.
5. Open a profile and explain its biography, interests and projects.
6. Show a no-results state and clear the filters.

## Staff section

1. Sign out and use the Staff demonstration account.
2. Show the owner-specific dashboard.
3. Add and edit an interest.
4. Try a duplicate to demonstrate validation.
5. Add and edit a project idea.
6. Show the named delete confirmation and complete a deletion.

## Engineering evidence

Finish with the issue tracker, merged pull requests, focused commits, CI result
and automated test folder.

The complete timed narration is maintained in
[docs/DEMO_SCRIPT.md](https://github.com/Rakib-208/setap-reff-supervisor-project-finder/blob/main/docs/DEMO_SCRIPT.md).
