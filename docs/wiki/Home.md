# ProjectFinder Wiki

ProjectFinder is a Django academic prototype for discovering final-year project
ideas and potential supervisors. It also provides protected Staff tools for
maintaining owned interests and project ideas.

All accounts, people and content are fictional.

## Current evidence

- Public repository with issue, branch and pull-request history
- 59 passing automated tests
- 97% assessed-code coverage
- Student and Staff role enforcement
- Owner-constrained staff changes
- Responsive desktop/mobile presentation
