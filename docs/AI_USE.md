# AI-use acknowledgement

Generative AI tools were used during this project for:

- planning implementation work from the assessment requirements;
- suggesting Django structures and interface copy;
- drafting code and automated tests;
- reviewing consistency between requirements, design, implementation and tests;
- preparing documentation.

AI output was not accepted as evidence without verification. The generated
application was migrated, seeded and exercised locally. Automated tests were
run to completion, coverage was measured, role and ownership failures were
checked, and the browser interface was reviewed at desktop and mobile sizes.

All stakeholder records and demonstration content are synthetic. AI was not
used to fabricate claims that real students or staff participated in the
requirements process.

The student remains responsible for understanding the submitted work,
recording the required demonstration and ensuring that the final report cites
and acknowledges AI use in line with University guidance.
