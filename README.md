# Supervisor Project Finder

A Django prototype that helps final-year students discover potential supervisors
and project ideas while allowing academic staff to maintain their own areas of
interest and proposed projects.

## Project status

Implementation is in progress. The planned assessed workflows are:

- seeded student and staff authentication;
- student staff-directory browsing, searching and filtering;
- read-only staff profiles containing interests and project ideas;
- staff-owned interest and project-idea creation, editing and deletion;
- responsive, accessible presentation and automated tests.

All demonstration records are fictional and are created solely for this
academic prototype.

## Development environment

The project uses Python 3.12+, Django 6.0 and SQLite. Detailed setup,
demonstration credentials and test instructions will be added as the
implementation is completed.
